## Portal community introduction

Title: FamilyHome: drawing, music, and timers for a first-generation Meta Portal

Body:

I work on FamilyHome at Marco Polo Research Lab.
It gives a first-generation Meta Portal a home screen for family activities.

Children can draw, play a piano or guitar, use timers, and switch between their profiles.
Those activities run on the device.
The game library opens separately installed games.
Calendar events, weather, Ask, and drawing share links use a companion service.

The original Meta launcher remains installed, and the setup guide includes the command to restore it.
FamilyHome's own application code uses MIT. Third-party components retain their own licenses.

The repository contains screenshots, a short demo, and the current setup requirements:
[FamilyHome](https://github.com/MarcoPoloResearchLab/FamilyHome).

I would value feedback on the home screen and the activities that would make an old Portal useful in your household.
