## Release and announcement gate

1. Complete P002 acceptance for parent authentication, device pairing, family isolation, and revocation.
2. Define the invited pilot's usage limits and service cost ownership.
3. Verify installation, update, offline use, and launcher restoration on the declared Portal model.
4. Verify the exact release APK and its signing identity.
5. Publish the approved APK and verify its download URL.
6. Update the setup guide for the accepted pairing process.
7. Capture the release build with sample data and review each image.
8. Review the destination's current rules and submission format.
9. Obtain the user's approval for the specific public announcement or submission.
10. Record each approved publication URL and its date.

## Initial pilot questions

- Can an invited parent install and pair a Portal without developer help?
- Can two households use connected features with separate data and usage records?
- Which local activity do families use after the first day?
- Can a parent remove a device and understand the effect on local data?
- Can a family restore the Meta home screen from the guide?

The pilot review can use installation results, voluntary feedback, and aggregate service usage.
Children's drawing content and Ask recordings are unnecessary for this review.
